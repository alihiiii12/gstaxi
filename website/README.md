# موقع GS Taxi التعريفي

## لوحة الإدارة
افتح: `http://127.0.0.1:8080/admin/`

كلمة المرور الافتراضية: `Gstaxi@2026`

غيّرها في `admin/config.php` (`SITE_ADMIN_PASSWORD`).

من اللوحة يمكنك:
- إضافة/حذف صور الكاروسيل
- نشر خبر مع صورة
- إضافة إعلان
- تعديل روابط Google Play و App Store و APK
- تعديل إنستغرام، فيسبوك، واتساب، تلغرام

## الصفحات العامة
- `index.html` الرئيسية
- `about.html` نبذة
- `contact.html` تواصل

## النشر
ارفع مجلد `website/` كاملاً (بما فيه `admin/` و `data/` و `uploads/`) واجعل PHP يعمل على الاستضافة، مع صلاحية كتابة على `data/` و `uploads/`.
