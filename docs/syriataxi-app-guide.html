مسار الراكب — من التسجيل إلى إنهاء الرحلة

١. التسجيل وتسجيل الدخول

  • التسجيل: الاسم + رقم سوري (09xxxxxxxx) + كلمة مرور + تأكيد OTP
  • تسجيل الدخول: رقم الهاتف + كلمة المرور
  • استعادة كلمة المرور عبر OTP

٢. أنواع الحجز

🚀 رحلة فورية Immediate

يُحدَّد الانطلاق والوجهة وفئة السيارة، ثم يُرسَل الطلب لجميع السائقين القريبين المتصلين. أول سائق يقبل يفوز بالرحلة.

📅 حجز مسبق Schedual

يُختار سائق محدد + موعد الرحلة. يُرسل تذكير قبل 30 دقيقة، وسؤال جاهزية قبل 5 دقائق. إلغاء تلقائي عند عدم الرد.

٤. تقدير السعر قبل الحجز

السعر = سعر الفتح + (المسافة × سعر الكيلو) + (الدقائق × سعر الدقيقة)

يُحسب من مسار OSRM أو Google Directions. يمكن تطبيق كود خصم قبل الإرسال. التحصيل نقداً عند الوصول.

٥. أثناء الرحلة

  • تتبع موقع السائق على الخريطة كل 12–14 ثانية
  • تأكيد وصول السائق عند وصوله
  • عرض العداد الحي أثناء مرحلة Running
  • الاتصال بالسائق مباشرة من التطبيق
  • إلغاء مسموح قبل بدء الرحلة (Pending / Reserved / DriverArrived)

مسار السائق — من الاتصال إلى إنهاء الرحلة

١. الدخول والجاهزية

  • يُنشَأ حساب السائق من لوحة الإدارة (لا يوجد تسجيل ذاتي للسائقين)
  • زر «اسحب للبدء» يفعّل وضع المتصل — يبدأ تتبع GPS وإرسال الموقع للخادم
  • إغلاق التطبيق لا يقطع الاتصال — يبقى أونلاين حتى الإيقاف اليدوي
  • يحتاج إذن «الموقع طوال الوقت» على أندرويد للعمل في الخلفية

٢. استقبال الطلبات

مصادر الطلب

  • إشعار FCM فوري
  • استطلاع موحّد كل 5–6 ثوانٍ
  • حوار منبثق للطلب الفوري

الإجراءات

  • قبول — أول سائق يفوز
  • رفض/تجاهل — يختفي من القائمة
  • إلغاء أثناء التوجه — قبل الوصول للراكب

٤. العدادان

النوعمتى يُستخدممصدر الأسعار
عداد رحلة التطبيق أثناء Running لطلب من التطبيق أسعار فئة السيارة
العداد الحر رحلة شارع بدون طلب تطبيق إعدادات لوحة التحكم

لا يمكن تشغيل العدادين معاً. قبول طلب تطبيق يُوقف العداد الحر تلقائياً.

٥. SOS — الطوارئ

زر SOS يرسل موقع السائق فوراً للوحة الإدارة. يظهر تنبيه أحمر للمسؤول حتى يُغلق يدوياً.

حالات الطلب (Trip Statuses)

Pending ← قبول ← Reserved ← وصول ← DriverArrived ← تأكيد ← AwaitingDestination ← Running ← إنهاء ← Finished   |   إلغاء في أي مرحلة ← Removed
الحالةالمعنىعلى الخريطة؟
Pendingبانتظار قبول سائقفوري: نعم
Reservedتم القبول — السائق في الطريقنعم
DriverArrivedالسائق وصل — بانتظار تأكيد الراكبنعم

Removedملغاةلا

منطق العداد الحر

عند البدء: التكلفة = سعر الفتح
أثناء الحركة: + (المسافة بالكم × سعر الكيلو)
أثناء التوقف: كل 60 ثانية → + سعر دقيقة الوقوف

قواعد GPS الذكية

  • يُحسب فقط عند حركة حقيقية (≥ 5م أو سرعة ≥ 1.5 كم/س)
  • يُرفض انجراف GPS أثناء التوقف
  • يُرفض القفزات الكبيرة (> 200م في تحديث واحد)
  • مهلة 3 ثوانٍ بعد الحركة قبل عد الوقوف
  • يستمر العد في الخلفية (مكالمات، تطبيقات أخرى)

الإعداد من الإدارة

  • سعر الفتح — يُضاف فور البدء
  • سعر الكيلومتر
  • سعر دقيقة الوقوف

يُعرض للسائق: التكلفة + الكيلو + الزمن + دقائق الوقوف مع إيصال نهائي.

لوحة الإدارة

📊 لوحة المؤشرات

إجمالي السائقين والزبائن، إيرادات اليوم وآخر 30 يوماً، طلبات نشطة، تنبيهات SOS.

🗺️ خريطة العمليات

عرض حي لمواقع السائقين والطلبات النشطة على الخريطة.

👥 إدارة السائقين

إضافة/تعديل/حذف سائقين، فئات السيارة، التسعير، إعدادات العداد الحر.

📋 الطلبات والتقارير

متابعة الطلبات، تصدير CSV، تقرير مالي PDF/Excel، آراء الراكبين.

🎟️ الخصومات

إنشاء كوبونات خصم وإشعار الزبائن بها.

🆘 تنبيهات SOS

استقبال تنبيهات طوارئ السائقين وإغلاقها بعد المعالجة.

صلاحيات الموظفين

يمكن للمسؤول إنشاء موظفين بصلاحيات محددة: عرض/تعديل السائقين، الطلبات، المناطق، التقارير، الخصومات.

ملخص API الرئيسية

  • POST /requests/store — إنشاء طلب
  • POST /requests/{id}/accept — قبول
  • POST /requests/{id}/finish — إنهاء
  • GET /driver/poll-snapshot — استطلاع موحّد
  • POST /drivers/updateLocation — موقع السائق
  • GET /requests/{id}/trip-tracking — تتبع حي
  • POST /emergency/sos — طوارئ
  • GET /reports/dashboard-summary — لوحة الإدارة
